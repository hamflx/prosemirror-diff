# Consumer DOM and range regression coverage

Base: `2147f859e915d1c8d9455b057d401abe69e911b2`.

The read-only example's initial tests exercised fixtures and range splitting,
but could not detect broken event wiring, stale highlights or stale error state.
The previous browser acceptance was manual. This batch makes those consumer
behaviors repeatable using the actual HTML and entry module in jsdom.

Six DOM integration tests cover initial rendering, exact bold/link/image
highlights in both documents, list selection, navigation boundaries and selected
state, unsupported-input cleanup, empty-state transitions and recovery, isolated
scenario metadata, and cancellation of an ordinary link click. Only scrolling
is stubbed because jsdom does not implement layout. These are not real-browser
layout, keyboard focus, image-load or navigation-isolation tests. Retained hrefs
still permit context-menu/middle-button navigation; the README states that limit.

[jsdom](https://github.com/jsdom/jsdom) 27.4.0 is a development-only dependency,
compatible with the existing Vite development Node requirement (20.19+, 22.12+
or 24+). Its packages are locked. No library runtime dependency, implementation,
demo behavior, or public API changed.

The block-query review also identified useful durable checks: every event's
before/after nodes must match both source slices, unchanged intervals must match,
and the matrix budget includes its empty row/column. These assertions now run
alongside the existing seeded reconstruction test, plus one exact-budget test.
README clarifies that only a changed middle with an empty side avoids the matrix;
multiple interleaved insertions may require alignment or fallback.

Validation: 128 tests pass (121 previous, six DOM tests and one budget test).
Source checkJs, UMD/CJS/ESM library builds, CJS block/metadata exports and the
existing demo production build pass. `git diff --check` passes.

Reproduce with `npm ci --ignore-scripts`, `npm test`, `npm run build`,
`npm run build:metadata-demo`, and
`npm exec --package=typescript@5.9.3 -- tsc --allowJs --checkJs --noEmit --target es2022 --moduleResolution bundler --module esnext --skipLibCheck src/index.js`.
Focused checks: `npx vitest run test/metadata-dom.test.js test/blocks.test.js`.

No runtime benchmark was rerun because runtime code is unchanged. The block
baseline remains in the preceding report. Next work should evaluate finer nested
rendering on explicit custom-node fixtures, and add browser-level automation only
with a clear browser/tooling support contract rather than treating jsdom as one.
