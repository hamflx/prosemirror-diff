Paste two fixed-schema ProseMirror document JSON values. Parsing and comparison run locally in this page's Worker; these inputs are not uploaded or persisted by this example. Each side is limited to 256 KiB UTF-8, with at most 2,000 combined document nodes. The existing schema and grid limits also apply. Editing either input cancels work and clears the old result. Drafts remain until you edit them or reload.

Fixed official table schema only. Both models and table grids are checked before comparison. Paths belong to this report, not persistent node identities. Parent and nested events overlap intentionally: do not add or apply them as separate edits. Positions are original half-open ProseMirror offsets, not row/column indexes.

Marks remain visible in each original. Selected metadata details require identical text and structure; mixed text/format edits are not independently classified. This view does not infer cell correspondence, detect moves, repair grids, or provide accept/reject edits. Empty boundaries are stated numerically; a highlighted containing table is context only. Column width metadata is retained in raw data, not used for pixel-exact layout.
