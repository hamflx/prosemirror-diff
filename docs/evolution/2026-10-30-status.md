## Remaining decisions, not promised features

- **Revision provenance:** [the January 2026 multi-snapshot question](https://discuss.prosemirror.net/t/how-to-get-one-consolidated-changeset-from-multiple-snapshots/8943)
  asks for consolidated changes with revision attribution. Its maintainer response
  distinguishes actual editing steps from whole-document replacements. A -> B -> A
  has changes in adjacent comparisons but none at the endpoints. Pair labels are
  not final-range provenance. Do not infer edit history or identities from this API.
- **Mixed formatting:** independent original formatting inventories and visible
  source marks do not establish cross-snapshot mark correspondence. Further UI or
  algorithm work needs a concrete input and expected coverage contract.
- **Filtering:** [current Tiptap Compare types](https://tiptap.dev/docs/compare/api-reference/types)
  document ignore options and tracked metadata. This is an existing alternative,
  not evidence that our raw-preserving comparator should silently filter content.
- **Performance:** existing sparse comparison and table consumer measurements did
  not justify general equality caching or table pagination. Zero-budget results
  are lower-precision comparisons, not evidence of a same-quality speedup. Budgets
  are not end-to-end time or memory guarantees.
- **Tables:** model validity, table-grid validity, HTML semantics and actual browser
  layout remain separate claims. Arbitrary schema adapters, cell identity/moves,
  pixel-exact sizing and accept/reject editing are outside the delivered example.

No new core option is justified solely by these remaining questions. Extend the
contracts only after a reproducible consumer scenario and independent review.
