## Contract

`compareDocumentBlocks` compares valid document Nodes from one schema instance,
with identical root markup and top-level block children. Exact `Node.eq` checks
include text, marks and attrs, using the public model API (also verified against
the locked model source). Prefix/suffix anchors are trimmed, then a bounded LCS
aligns the remaining blocks. Ties consume old blocks first. Unmatched runs produce
insert/delete/replace events with both original UTF-16 ranges and Node arrays.
Arrays are fresh; Node values are shared and must be treated as immutable.

Root markup changes are rejected rather than omitted. Nested changes replace
the whole containing top-level block. Repeated blocks are deterministic positional
matches, not identity/move detection. No mixed document or editor transaction is
constructed. Existing metadata-only and diffEditor behavior is unchanged.

Default matrix budget: 100,000 cells, configurable from 0 through 1,000,000.
An oversized changed middle becomes a single range with `fallback: true`.
Input validation, prefix/suffix checks, subtree equality and output costs are
outside that bound. This is not a whole-call deadline guarantee.

## Acceptance and measurements

121 tests pass: 105 existing and 16 new. Coverage includes strict containers,
empty blocks/documents, images, metadata, Unicode positions, budget fallback,
repeated blocks, invalid roots/schemas/budgets, and one 200-pair seeded test that
reconstructs both directions with default and zero budgets. The loop is one
test, not 200 additional tests. Source checkJs, three library bundles, CJS export
smoke and the existing demo production build pass.

Commands: `npm test`, `npm run build`, `npm run build:metadata-demo`,
`npm exec --package=typescript@5.9.3 -- tsc --allowJs --checkJs --noEmit --target es2022 --moduleResolution bundler --module esnext --skipLibCheck src/index.js`,
`node test/benchmark-blocks.mjs`.

The benchmark preconstructs inputs, changes every tenth paragraph, warms three
times, then times 15 complete calls including validation. Median / sample p95
(ms), default budget versus zero-budget fallback:

| Blocks | Default events / fallback | Default median / p95 | Zero-budget median / p95 |
| --- | --- | --- | --- |
| 10 | 1 / false | 0.084 / 0.217 | 0.029 / 0.498 |
| 100 | 10 / false | 0.702 / 1.538 | 0.055 / 0.143 |
| 1000 | 1 / true | 0.403 / 1.637 | 0.226 / 0.896 |

These modes return different precision; the values are a baseline, not a speedup
claim. The 1000-block case deliberately demonstrates fallback, not exact LCS at
that size. No new dependencies. Next decisions should follow nested-rendering
fixtures and explicit identity/ambiguity contracts before refining matched blocks.
